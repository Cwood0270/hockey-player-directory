# Scaffold notes — Hockey Ops Player Directory

Date: 2026-09-03

Official starter: `npx @tanstack/cli@latest create` (TanStack Start + React + TypeScript + Vite + Tailwind CSS v4). No player data, auth, Supabase, or custom hockey routes were added.

## How to start the app

From this project folder:

```bash
npm run dev
```

Then open **http://localhost:3000**.

Other scripts from the starter:

```bash
npm run build      # production build
npm run preview    # preview the production build
```

## Key folders and files

| Path | What it is |
|------|------------|
| `package.json` | Dependencies and scripts (`dev` runs Vite on port 3000). |
| `vite.config.ts` | Vite config. Includes `tanstackStart()`, `@vitejs/plugin-react`, and `@tailwindcss/vite`. |
| `tsconfig.json` | TypeScript compiler options and `#/*` / `@/*` path aliases into `src/`. |
| `src/styles.css` | Global styles. Tailwind v4 is CSS-first: `@import "tailwindcss"` (no `tailwind.config.ts`). |
| `src/router.tsx` | Creates the TanStack Router instance from the generated route tree. |
| `src/routes/` | File-based routes shipped by the starter. |
| `src/routes/__root.tsx` | Root layout (document shell, header/footer, stylesheet link). |
| `src/routes/index.tsx` | Home route (`/`). |
| `src/routes/about.tsx` | About route (`/about`) from the starter. |
| `src/components/` | Starter Header, Footer, and ThemeToggle. |
| `src/routeTree.gen.ts` | Generated by the router CLI / Vite plugin. Do not edit by hand. |
| `docs/` | Course docs (`requirements-brief.md`, this file, workspace checklist). |

## Tailwind v4

This course uses Tailwind v4 (CSS-first):

- Import lives in `src/styles.css`: `@import "tailwindcss"`
- Vite plugin: `@tailwindcss/vite` in `vite.config.ts`
- There is **no** `tailwind.config.ts`
